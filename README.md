A complete, original 2D top-down cooking game set in an Indonesian warteg. One solo chef, 180-second shifts: take orders from the board, gather ingredients from 8 racks, chop at the cutting board, fry in 2 woks, cook rice, assemble dishes at the plating table, and serve before patience runs out. 5 recipes unlock over time, with combos, tips, and a 3-star shift rating.

Play it: open `game/index.html` in a desktop browser — no network, no build step. Keyboard (WASD/arrows + E/Space + Q + R) and mouse.

Built for the [make.fun Best Cooking Game bounty](https://make.fun/bounty/best-cooking-game-20261125-0137).
